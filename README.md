Python Expense Tracker

A simple command-line expense tracker built using Python.
This project helps users record daily expenses, categorize them, and save them permanently using JSON files.

Features:
- Add expenses
- View all saved expenses
- Calculate total expenses
- Calculate category wise expenses
- Save expenses automatically
- Load previous expenses on startup
- Input validation
- Category system
- JSON file storage

Categories:
Current supported categories:

- Food
- Travel
- Clothes
- Other

Technologies Used:
- Python
- JSON
- File Handling

How to Run:
1. Install Python
2. Clone the repository
3. Run the program
